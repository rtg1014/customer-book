# 고객 수첩

보험설계사용 가입자 · 소속 가족 · 차량 정보를 **폰 안에만** 저장하는 웹앱(PWA)입니다.
서버·로그인·인터넷 연결 없이 동작하고, 고객 정보는 어디로도 전송되지 않습니다.

## 기능

- **가입자 중심 구조:** 고객 1명 = 보험 가입자(보험료 내는 분) 1명
  - 가입자 본인 차량 여러 대
  - 소속 가족(배우자·자녀·부모·형제자매·기타) 여러 명, **가족마다 그 가족의 차량 여러 대**
  - 가족을 등록할 때 그 가족의 차량도 바로 함께 등록
- 차량: 차번호, 차종, 보험 만기일, 메모
- **눌러서 복사:** 전화번호·차번호·차종·사고접수 번호를 누르면 복사되고 "복사되었습니다" 알림 (전화 앱으로 넘어가지 않음)
- 전화번호 입력 시 **하이픈(-) 자동 입력** (숫자만 누르면 010-1234-5678)
- 검색: 이름 / 초성(ㄱㅅㅎ) / 전화번호 뒷자리 / 차번호 뒷자리 / 차종 / 가족 이름
  - 가족 이름이나 가족 차번호로 찾아도 가입자 카드가 나오고, 무엇이 일치했는지 표시
- 카드 보기(가입자 아래로 본인·가족 차량 줄) / 표 보기(차 1대당 1줄, 칸 제목 눌러 정렬)
- 만기일은 **날짜 + 남은 날**로 표시 (예: 만기 2026.9.26 · D-2), 30일 이내는 노란색, "만기 임박만" 모아 보기
- 현대해상 사고접수 번호(1588-5656) 표시 · 복사 (설정에서 수정 가능)
- 글씨 크기 3단계 (보통 / 크게 / 아주 크게) — 목록과 가입자 상세 화면 위쪽에서 바로 조절
- 엑셀(.xlsx) 백업 · 복원, PC 엑셀로 한꺼번에 입력하는 빈 양식
  - "백업 파일 저장하기": 엑셀 파일을 폰에 저장한 뒤 카톡 첨부 방법을 안내 (안드로이드 크롬은 웹페이지의 .xlsx 직접 공유를 막음)
  - 엑셀 형식: 한 줄 = 차 1대. 칸은 `가입자 | 가입자휴대폰 | 가입자메모 | 관계 | 운전자 | 운전자휴대폰 | 차번호 | 차종 | 만기일 | 차량메모`
  - 가입자 본인 차는 관계에 `본인`, 차가 없는 가족은 차 칸을 비운 한 줄
- 4자리 잠금 비밀번호(선택)
- 삭제·불러오기 후 "되돌리기", 작성 중 뒤로가기 시 확인, 안드로이드 뒤로가기 버튼 지원

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 뼈대 |
| `app.js` | 화면, 저장(IndexedDB), 검색, 정렬, 백업 전부 |
| `style.css` | 디자인 (rem 단위 → 글씨 크기 설정에 따라 전체가 커짐) |
| `xlsx-lite.js` | 외부 라이브러리 없이 엑셀 파일 만들기/읽기 |
| `sw.js` | 오프라인 동작용 서비스 워커 |
| `manifest.webmanifest`, `icons/` | 홈 화면 앱 설치 정보 |

빌드 과정이 없습니다. 파일 그대로 올리면 됩니다.

## PC에서 미리 보기

```bash
cd customer-book
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기 (개발자도구 > 모바일 화면으로 보기)
```

## 배포 (GitHub Pages, 무료)

홈 화면 설치와 오프라인 동작에는 https 주소가 필요합니다.

1. GitHub에 새 저장소 생성 (예: `customer-book`, Public — Pages 무료 사용 조건)
   - 올라가는 건 앱 코드뿐이고 **고객 데이터는 폰에만 있으므로 공개 저장소여도 괜찮습니다.**
2. 이 폴더 내용을 올리기
   ```bash
   cd customer-book
   git init && git add . && git commit -m "고객 수첩 1.0"
   git branch -M main
   git remote add origin https://github.com/<아이디>/customer-book.git
   git push -u origin main
   ```
3. 저장소 **Settings → Pages → Branch: main / (root) → Save**
4. 1~2분 뒤 `https://<아이디>.github.io/customer-book/` 로 접속

## 어머님 폰(갤럭시)에 설치

1. 위 주소를 카톡으로 보내서 **크롬** 또는 **삼성 인터넷**으로 열기
2. 크롬: 오른쪽 위 ⋮ → **홈 화면에 추가** → 설치
   삼성 인터넷: 아래 ≡ → **현재 페이지 추가 → 홈 화면**
3. 홈 화면의 "고객수첩" 아이콘으로 실행 (이후 인터넷 없어도 열림)

> 주의: 크롬으로 설치했으면 계속 그 아이콘으로 쓰세요. 크롬과 삼성 인터넷은 저장 공간이 달라서
> 다른 브라우저로 열면 빈 목록이 보입니다. (데이터가 사라진 게 아닙니다)

## 백업 (꼭 안내해 주세요)

- 데이터는 폰 브라우저 저장 공간에만 있습니다. **브라우저 데이터 삭제, 앱 초기화, 폰 교체** 시 사라질 수 있습니다.
- 설정 → **백업 파일 저장하기** → 안내대로 카톡 '나와의 채팅'에서 ＋ → 파일 → customer-backup 파일을 보내 두면 됩니다. 30일 넘게 백업을 안 하면 목록 위에 알림이 뜹니다.
- 새 폰에서는 앱 설치 → 설정 → **백업·엑셀 파일 불러오기** → 받아 둔 파일 선택.
- 백업 파일은 일반 엑셀 파일이라 PC에서 열어 볼 수 있습니다. 엑셀에서 고친 뒤 불러와도 고친 내용이 반영됩니다.
  (`복원용데이터` 시트는 건드리지 마세요)

## 앱을 고친 뒤 다시 배포할 때

`sw.js` 맨 위의 `VERSION` 값을 올린 뒤(예: `v1.0.1`) 푸시하세요.
안 올리면 폰에 예전 파일이 계속 남아 있습니다. 폰에서는 앱을 두 번 껐다 켜면 새 버전이 적용됩니다.

## 알아 둘 한계

- 잠금 비밀번호는 폰을 잠깐 빌려줄 때 **가림막** 정도입니다. 데이터 자체를 암호화하지는 않으며,
  "비밀번호를 잊으셨나요?"로 잠금을 끌 수 있습니다(고객 정보는 유지).
- 여러 기기 간 자동 동기화는 없습니다(의도적으로 서버 없음). 옮길 때는 백업 파일을 쓰세요.
- 사고접수 번호는 현대해상 대표번호(1588-5656, 손해보험협회 자동차보험 포털 기준 2026년 9월)이며, 설정에서 고칠 수 있습니다.
